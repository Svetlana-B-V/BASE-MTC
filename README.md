# Определение эмоционального состояния клиента по аудиоэмбеддингам (Голос клиента, МТС)

Решение задачи речевой аналитики для классификации коротких аудиореплик клиентов контакт-центра на четыре класса эмоций: `angry`, `neutral`, `positive` и `sad`.

---

## 📁 Структура проекта и описание файлов

В корне проекта находятся следующие файлы и папки:

* **`train.py`** — скрипт для воспроизводимого обучения модели. Автоматически фиксирует случайный `seed`, разбивает данные на тренировочную и валидационную выборки с учетом стратификации, обучает пайплайн (масштабирование + логистическая регрессия), выводит метрику `macro-F1` и сохраняет веса модели.
* **`predict.py`** — скрипт для инференса. Загружает обученные веса (`model_weights.pkl`), энкодер классов (`label_encoder.pkl`) и сгенерированный `seed`, производит классификацию открытого тестового набора (`public_test.npz`) и формирует итоговый файл с ответами для платформы.
* **`requirements.txt`** — файл со списком зависимостей Python и их версий.
* **`train.npz`** — обучающий набор данных, содержащий эмбеддинги аудиофайлов и целевые метки (эмоции)[cite: 1].
* **`public_test.npz`** — открытая тестовая выборка (эмбеддинги без ответов)[cite: 1].
* **`sample_submission.npz`** — пример файла с ответами[cite: 1], демонстрирующий правильный формат структуры `.npz` архива.
* **`venv/`** — папка локального виртуального окружения Python (создается автоматически).

---

## ⚙️ Описание ключевых функций и логики

1. **Балансировка классов (`class_weight='balanced'`)**: Так как класс `neutral` значительно преобладает в данных, взвешивание классов позволяет модели не смещать предсказания в сторону большинства, что критически важно для метрики **macro-F1**[cite: 1].
2. **Линейная модель (Логистическая регрессия)**: Использование линейного классификатора с оптимизатором `solver='saga'` поверх готовых эмбеддингов нейросети минимизирует количество настраиваемых параметров модели (что высоко ценится жюри) и обеспечивает высокую скорость обучения.
3. **Воспроизводимость**: Скрипты используют динамически генерируемый и сохраняемый в файл `seed.txt` случайный сид, который прописывается в итоговое название файла с предсказаниями (`submission_seed_{SEED}.npz`), как того требуют правила соревнования.

## 🚀 Инструкция по запуску проекта

### Шаг 1. Клонирование и открытие проекта
Откройте папку проекта в терминале (например, во встроенном терминале **Visual Studio Code**).

### Шаг 2. Создание и активация виртуального окружения
Создайте виртуальное окружение и активируйте его:
```bash
# Создание окружения
python -m venv venv

# Активация на Windows (PowerShell / CMD)
venv\Scripts\activate

# Активация на macOS / Linux
source venv/bin/activate
В терминале выполните:

Bash
python train.py
Дождитесь завершения обучения (теперь оно пройдет значительно быстрее).

Затем запустите предсказание:

Bash
python predict.py
